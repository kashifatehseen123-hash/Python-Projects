# Python Projects

This repository contains Python projects that I create while learning and improving my programming skills.

## Projects

### Student Grade Calculator
A simple Python program that:
- Takes the student's name
- Accepts marks for 3 subjects
- Calculates the average
- Assigns a grade based on the average

## Technology Used
- Python 3.12

## How to Run

1. Install Python 3.x
2. Open the project in VS Code
3. Run `grade_calculator.py`
4. Enter the student name and marks when prompted.
