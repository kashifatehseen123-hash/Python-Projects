# Python Projects

A collection of Python projects created to practice programming fundamentals and problem-solving skills.

## Projects

### 🐍 Student Grade Calculator

A simple Python program that calculates a student's average marks and assigns a grade.

### Features

* Takes the student's name
* Accepts marks for 3 subjects
* Calculates the average
* Assigns a grade based on the average

## Technology Used

* Python 3.12

## How to Run

1. Install Python 3.x
2. Open the project in VS Code
3. Run `grade_calculator.py`
4. Enter the student name and marks when prompted

## Learning Goals

This project helped me practice:

* Python basics
* Variables and input
* Conditional statements
* Calculations
* Basic problem-solving
